# (3) 성능 목표 · 평가 지표

> 핵심 3개 모듈(**① 생성엔진 · ② HCI Encoder+MLP · ③ 버티컬 QLoRA**) 중심의 정량 지표. 목표치는 **익명·세션 기반 HCI Feature** 조건을 반영한 현실적·달성 가능 수준. (세계 최고수준은 대부분 고객 이력 포함 조건)

## 평가 방법 (요약)
- **①** 명세→빌드·검증 통과율 / 기준 대비 위치·크기 mean IoU + Playwright·Appium E2E
- **②** SSL 사전학습 표현을 **freeze + 선형 probe** 학습해 downstream AUC / 세션 단위 Intent 분류 F1 · Rage·Dead Click 라벨 기반 AUC
- **③** 생성물 JSON Schema 검증 + 브랜드 룰·금지표현 검수 통과율 / vertical 라벨 대비 어댑터 선택 정확도
- **지원** 기대 이벤트 대비 수집·유실·중복률 / A/A 반복 FPR

## 주요 산식
- 생성 성공률 = 통과/전체 × 100 · 재현율 = mean IoU · E2E = 통과 시나리오/전체
- 인코더 표현 = SSL freeze 선형 probe ROC-AUC · Intent F1 = `2·P·R/(P+R)` · 이탈 = ROC AUC
- Schema 유효율·브랜드 준수율·금지표현 위반율·라우팅 정확도 = 각 (해당/전체) × 100
- 수집률 = 실수집/기대 × 100 · A/B FPR = 오탐 A/A / 전체 A/A × 100

## 부록 · 지표 개정 사유 (보고용)
**기존 6대 지표를 3개 모듈로 재편했고, 기존 지표는 전부 유지(재배치·정정·통합)** 했다. 아키텍처 변경 — (a) HCI Encoder **SSL 사전학습**, (b) rule-based **Policy 제거 → LLM이 Blueprint 직접 생성**, (c) 출력을 **구조화 콘텐츠 명세(JSON Schema)** 로 고정 — 에 맞춰 **인코더 표현품질·QLoRA 생성품질** 항목만 신규 추가했다. **기존 목표치는 손대지 않음.**
