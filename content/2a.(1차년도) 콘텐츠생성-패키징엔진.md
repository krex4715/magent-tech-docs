

# (2-1) 1차년도 · HTML5/JS/CSS 콘텐츠 생성·패키징 엔진


## 목표
사용자 옵션 선택값 + 업로드 이미지·영상을 
→ **실행 가능한 HTML5 인터랙티브 콘텐츠**로 자동 조립·검증·패키징한다.


## 개발 내용
- 옵션 선택값과 업로드 이미지·영상의 **표준화** 및 콘텐츠 템플릿 **자동 매핑** 구조 구현
- 클릭·스와이프·드래그앤드롭·스크래치 등 **인터랙션 로직**을 HTML5/JS/CSS 컴포넌트로 자동 조립
- 생성 결과물의 미리보기 · 실행 오류 검증 · 리소스 최적화 · 배포용 **ZIP 패키징** 기능 개발

## 5단계 파이프라인
![[1차_콘텐츠생성엔진_5단계.png]]

| 단계  | 이름                      | 핵심 기능                                                                            | 산출물(Output)                               |
| --- | ----------------------- | -------------------------------------------------------------------------------- | ----------------------------------------- |
| ①   | **Input Normalizer**    | 옵션 파서, 에셋 업로더, 미디어(포맷/해상도/비율) 정규화, Asset Manifest 생성                             | 정규화 입력 JSON + Asset Manifest              |
| ②   | **Template Mapper**     | 템플릿 레지스트리 검색, 옵션→컴포넌트 매핑 Rule Engine, 슬롯 바인더, 레이아웃 Resolver                      | Template Blueprint                        |
| ③   | **Interaction Builder** | HTML DOM 자동 생성, CSS 토큰 적용, JS Action Composer(클릭/스와이프/드래그앤드롭/스크래치), 컴포넌트 레지스트리   | index.html + styles.css + interactions.js |
| ④   | **Preview Validator**   | 렌더 미리보기, Static Lint(누락 에셋·broken path), Runtime Check(JS 오류·이벤트 바인딩), 모바일 QA 룰  | 검증 리포트 + 수정 포인트                           |
| ⑤   | **Packager & Exporter** | Asset Optimizer(이미지 압축·코드 minify), Bundle Builder, Manifest Writer, ZIP Exporter | **실행 가능한 HTML5 배포 패키지**                   |


예를들면
- 입력: 
  `InputOption = {optionId:'interaction', value:'swipe'}`, 
  `Asset = {assetId:'img01', type:'image', ratio:'16:9'}`

- 매핑:
   `Template: promo_banner_v2`, 
   `Rule: interaction=swipe -> carousel component`
   
- 출력 파일 트리: 
  `/index.html`, 
  `/assets/images`, 
  `/css/styles.css`, 
  `/js/interactions.js`, 
  `/manifest.json`, 
  `package.zip`
