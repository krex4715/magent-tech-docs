## 1. HCI Encoder 학습 & MLP Head 학습 — 방법론이 비어 있음

핵심 AI인 **② HCI Encoder + MLP Head**는 사실상 두 단계 학습인데, 기술서에 **"무엇을 만든다"**는 있지만 **"어떻게 학습시킨다"**가 거의 없음. 심사위원이 딥러닝 백그라운드면 여기서 바로 질문 들어옴.

### (a) HCI Encoder — Self-Supervised 학습 계획이 있어야 함
- 행동 이벤트 시퀀스를 표현(Representation)으로 바꾸는 Encoder인데, **라벨 없는 원천 로그가 대부분**임 → self-supervised가 자연스러운 선택.
  
- 최소한 **어떤 pretext task로 사전학습할지** 방향은 적혀 있어야 설득력이 생김. 예시 수준이라도:
  - **Masked Event Modeling** — 시퀀스 중간 이벤트를 가리고 복원 (BERT식)
  - **Next-Event Prediction** — 다음 행동 예측 (GPT식)
  - **Contrastive / Triplet** — 유사 세션끼리 당기고 다른 세션은 밀기 (세션 임베딩 품질↑)
    
- 지금은 이 부분이 공란이라 *"인코더를 학습한다"*가 구호처럼 보임. **1~2줄이라도 계획을 박아두는 게 방어에 유리.**

### (b) MLP Head — Labeling을 어떻게 할 것인가
- Head는 intent/friction/interest/drop-off **지도학습(supervised)**인데, **정답 라벨을 어디서 얻느냐**가 안 나와 있음.
- 미세행동에는 애초에 정답이 없음 → **라벨링 전략 자체가 R&D 항목**이어야 함. 짚어줄 후보:
  - **약지도(Weak supervision)** — 규칙 기반 라벨링 함수로 노이즈 라벨 대량 생성 (Snorkel식)
  - **시간 감쇠 소프트라벨** — 구매/이탈 같은 최종 결과를 이전 행동에 역전파, `label_t = γ^(T−t)`
  - **행동 결과 기반** — 실제 전환/이탈을 정답으로 삼아 사후 라벨링
  - 클래스 불균형 대비 **Focal loss** 등도 언급하면 완성도↑
- 요지: **"라벨을 어떻게 만들지"가 곧 연구의 난이도이자 차별점**인데 지금은 비어 있음.

## 2. 성능지표 ↔ 연구내용이 따로 논다

성능목표/평가지표가 **연구개발 목표(사업 성과: ROAS 2배, 비용 90%↓)** 위주로만 잡혀 있고,
 **실제로 만드는 4개 모듈**과 지표가 매핑이 안 됨. 심사에서 *"그래서 이 모델이 잘 학습됐다는 건 뭘로 확인하나?"* 가 나오면 답이 궁색해짐.

### 모듈별로 지표가 하나씩 있어야 함
| 모듈                            | 성격         | 있어야 할 성능지표(예)                              |
| ----------------------------- | ---------- | ------------------------------------------ |
| **① Generation** (콘텐츠 생성·패키징) | 비-AI 소프트웨어 | 렌더 성공률, 생성 소요시간, 템플릿 커버리지                  |
| **② HCI Encoder + MLP**       | 딥러닝(핵심)    | 예측 정확도/F1, AUC, (인코더) downstream 성능·임베딩 품질 |
| **③ Policy**                  | 규칙 + 경량 ML | 정책 추천 채택률, 개선 적중률, 설명가능성(SHAP 기여도 타당성)     |
| **④ QLoRA LLM**               | 생성형        | 카피 품질(사람 평가/승률), 브랜드가이드 준수율, 금지표현 위반율      |

- 지금처럼 사업 성과지표(ROAS 등)만 있으면 **"모델 성능"과 "사업 성과" 사이가 붕 뜸.** 
- **연구내용 = 4개 모듈**이니, **평가지표도 4개 모듈에 각각 대응**시켜야 "목표–연구–검증"이 한 줄로 이어짐. 
- 특히 ②·④(딥러닝/생성형)는 **정량 지표 + 측정 방법(데이터셋·평가 프로토콜)**까지 있으면 가장 강함.
