

## LoRA (Low-Rank Adaptation)
**핵심 아이디어**: 원래 모델 가중치(W)는 **얼려두고(freeze)**, 그 옆에 아주 작은 **보조 행렬 두 개(A·B)만** 새로 학습한다.
- 원래 가중치 W는 그대로 두고, 변화량 ΔW ≈ **B·A** (저차원, low-rank)만 학습.
- 학습해야 할 파라미터가 전체의 **1% 미만**으로 줄어든다.
- 학습이 끝나면 이 작은 A·B 묶음이 하나의 **"어댑터(Adapter)"** 파일이 된다 (수 MB~수십 MB).

**장점**
- 큰 모델 하나(Base)를 공유하고, **어댑터만 갈아 끼우면** 업종별 특화 모델이 된다.
- 게임용 어댑터 / 웹툰용 어댑터 / 커머스용 어댑터를 따로 저장·교체 가능 → 기술서의 **Adapter Routing**이 바로 이것.

## QLoRA (Quantized LoRA)
LoRA에 **양자화(Quantization)**를 더한 것.
- Base 모델을 **4bit로 압축(양자화)**해서 메모리에 올린다 (예: 기술서의 `Qwen2.5 7B / 4bit`).
- 그 위에서 LoRA 어댑터를 학습한다.
- 결과: 원래 수십 GB VRAM이 필요하던 파인튜닝을 **소비자용 GPU 한 장(예: 24GB)** 수준에서 가능하게 함.

| | Full 파인튜닝 | LoRA | QLoRA |
|---|---|---|---|
| Base 가중치 | 전부 업데이트 | 얼림(freeze) | 얼림 + **4bit 양자화** |
| 학습 대상 | 전체(수십억) | 작은 어댑터(A·B) | 작은 어댑터(A·B) |
| 메모리 | 매우 큼 | 작음 | **가장 작음** |
| 업종별 교체 | 모델 통째로 | 어댑터만 교체 | 어댑터만 교체 |
