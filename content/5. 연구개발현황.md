## 데이터 확보 현황 (슬라이드 13) — 데이터 해자(Moat)
- **현재 약 1만 건 이상**의 퍼스트파티 데이터 수집 (HTML5 콘텐츠·자사 앱/웹·랜딩페이지에 트래커 삽입 → 클릭·드래그·스와이프·체류시간·망설임·이탈단계)
- 자체 확보 + 고객사 콘텐츠 집행 과정의 퍼스트파티 행동 데이터를 **계약 기반** 확보

### 데이터 확보 전략
- 대규모 플랫폼·금융사와 **NDA·계약·공동 PoC·광고 집행 계약**을 통해 대규모 HCI 행동 데이터 확보
- 순 광고 성과가 아닌 **사용자 행동 기반 미세 데이터**(클릭·터치·스와이프·체류·망설임·이탈·반복 클릭)
- 외부 구매가 어려운 플랫폼·금융사 퍼스트파티 데이터 → **후발주자가 단기 복제하기 어려운 데이터 해자**

### 추가 확보 계획
- **토스, IM뱅크, 배민** 등 대규모 트래픽 기업과 NDA·계약 → 향후 **약 1억 건 이상** 규모 행동 데이터 확보 기반
- 수집 데이터를 Intent Confidence Score / Friction Score / Drop-off Risk Score 등 **파생 의도변수**로 변환
- 고객사·캠페인 증가 → 데이터 누적 → 모델 성능 개선의 **HCI 데이터 플라이휠**
