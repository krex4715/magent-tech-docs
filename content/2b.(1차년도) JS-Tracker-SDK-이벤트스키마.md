
# (2-2) 1차년도 · HCI 미세행동 수집용 JS Tracker/SDK + 이벤트 스키마





## 목표
클릭·스와이프·드래그·스크롤·체류시간·반복행동·이탈구간을 수집하는 
**JS Tracker/SDK**와 공통 이벤트 스키마를 만든다.


## 개발 내용
- 미세행동 수집용 **이벤트 리스너 + JS Tracker/SDK** 구현
- 캠페인·콘텐츠·Variant·세션·UI 요소 단위로 행동을 식별하는 **공통 이벤트 스키마** 정립
- 데이터 배치 전송·재전송·중복 방지·누락 검증·원천 로그 저장을 포함한 **안정적 수집 파이프라인** 구축



## 핵심 기술
> 일반 SDK 로그 수집을 하는게 아니라
> 플랫폼별 Raw-Data를 **정확한 순서와 의미를 가진 HCI 행동 데이터로 복원**하는 기술.



### 1. Semantic Interaction Binding — 의미 결합
- UI 요소를 CTA·상품카드·결제버튼 등 **비즈니스 의미 단위**로 식별하는 Interaction Ontology
- DOM 구조가 바뀌어도 동일 행동 의미를 유지하는 **Semantic Element ID** 체계
- 플랫폼별 상이한 이벤트를 공통 HCI 행동 Descriptor로 변환하는 의미 표준화


### 2. Event-time Sequence Reconstruction — 순서 복원
- 이벤트 발생시간 · 서버 수신시간 · 순번을 결합한 **행동 순서 재구성**
- 네트워크 지연·역순 도착을 보정하는 세션 내 이벤트 재정렬
- 망설임·반복행동·전환 직전 경로의 정확한 시계열 복원



### 3. Low-overhead Adaptive Tracking — 경량 수집
- 고빈도 스크롤·드래그 이벤트의 **Throttling** 및 중요도 기반 선택 수집
- 로컬 버퍼 + 비동기 배치 전송으로 렌더링 영향 최소화
- 디바이스 성능·네트워크 상태에 따른 수집 빈도 자동 조절



### 4. Reliable Event Integrity — 무결성
- **Idempotency Key** 기반 중복 제거 + **ACK** 기반 전송 성공 확인
- 네트워크 단절 시 로컬 임시저장 후 재연결 시 자동 재전송
- 수집률·유실률·중복률·지연시간을 자동 검증하는 데이터 품질 모니터링
