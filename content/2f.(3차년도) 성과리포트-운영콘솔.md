
# (2-6) 3차년도 · 자동 성과 리포트 + Enterprise 운영 콘솔


## 목표
CTR·CVR·ROAS + HCI 행동지표를 자동 집계·시각화하고, 
다중 고객사를 관리하는 **멀티테넌트 운영 콘솔**을 만든다.



## 개발 내용
- CTR·CVR·ROAS + HCI 행동지표를 고객사·캠페인·콘텐츠별로 **자동 집계·시각화**하는 리포트 기능
- 다중 고객사·사용자 권한·캠페인·콘텐츠·모델·정책을 통합 관리하는 **멀티테넌트 운영 콘솔**
- 성과 이상징후·개선 권고·Winner 이력의 **자동 리포팅** 및 파일·API 기반 결과 제공



## 아키텍처
![[3차_리포트_운영콘솔.png]]

### 1. 데이터 수집·집계 파이프라인
원천(광고 플랫폼/HCI 로그/전환 데이터/콘텐츠·모델·정책 이벤트) → Kafka/Kinesis → Flink/Spark(정제·세션화·지표계산·윈도우/중복 보정) → 저장(ClickHouse Realtime OLAP / Raw Store S3·HDFS) → 모델·분석 레이어(Feature Store, Metric Store, ML/Anomaly Engine) → 서빙(API Gateway REST/GraphQL, Report Service).

### 2. 데이터 모델 (핵심 스키마)
`dim_tenant` · `dim_campaign` · `dim_creative` · `dim_variant` · `fact_performance`(impressions/clicks/conversions/revenue/ctr/cvr/roas) · `fact_hci_metrics`(avg_dwell_time·hesitation·interaction_depth·scroll_depth·rage_click·exit_rate) · `fact_ab_test`.

### 3. 리포트 생성 로직
- 지표 계산(SQL 예시: CTR/CVR/ROAS 집계)
- HCI 지표 집계(세션 단위 mean/sum)
- **이상징후 탐지**: 이동평균/표준편차 기반 Z-score 또는 예측모델 잔차
- **개선 권고 규칙 엔진**: 예) `ctr < p25 and hesitation_time > p75 → "CTA 문구 개선/간결한 CTA"`

### 4. Enterprise 운영 콘솔 핵심 기능
- **4-1 멀티테넌트·권한**: 테넌트 개설, RBAC, 사용자/팀/권한, 데이터 접근 필터링, Tenant Isolation(Row Level Security)
- **4-2 캠페인/콘텐츠/모델/정책 관리**: CRUD, Variant/A-B/Feature/Policy 버전 관리, 변경 이력/승인 프로세스
- **4-3 리포트/대시보드**: 실시간 대시보드, 스케줄링, 비교 분석, 드릴다운, 이상징후/권고 센터
- **4-4 결과 제공**: 파일 내보내기(CSV/Excel/PDF), API(REST/GraphQL), Webhook 알림, 이메일 리포트

### 5. 리포트 & 알림 자동화 파이프라인
현황 쿼리 → 인사이트 생성(트렌드/이상징후/원인/권고) → 템플릿 렌더링 → 자동 발송(이메일/S3/콘솔/Webhook) → 외부 제공.

### 7. A/B Winner & 이력 연동
A/B 결과 집계 → 통계 검정 → Winner 결정 → 이력 저장(`ab_test_history`) → 다음 액션 자동 연동(콘텐츠 교체/정책 업데이트/후속 테스트 생성).
